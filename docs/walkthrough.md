# Walkthrough: BackupManager 3단 카드 버튼 통합 및 유동 경로 설정 구현 완료

기존 독립형 모던 웹 UI 대시보드 구조를 대폭 혁신하여, 화면 영역을 효율적으로 사용하고 설정을 손쉽게 관리할 수 있는 **3단 카드 버튼 통합 및 유동 경로 저장 관리 기능**을 성공적으로 완비하였습니다.

---

## 🛠️ 주요 구현 및 개선 사항

### 1. 설정 저장소 동적 연동 및 탐색 창 팝업 (`config.json` & `/api/browse_folder`)
* **일렬 컴팩트 저장소 바 (Single-row Config Bar)**: 기존의 수동 텍스트 입력 방식을 완전히 탈피하여, `"로컬 백업 저장소 : [현재 경로]"` 형태로 타이틀 정보와 폴더 경로를 한 줄에 가독성 높은 glowing 코드 태그박스로 나란히 표시했습니다.
* **윈도우 탐색 폴더 선택기 연동 (Native Directory Chooser Dialog)**:
  - `[📂 경로 변경]` 버튼을 누르면 Flask 백엔드가 즉시 윈도우 네이티브 디렉토리 선택 모달 대화상자(Tkinter 기반)를 **화면 최상단(`-topmost`)에 팝업**합니다.
  - Flask 백그라운드 스레드와의 간섭이나 UI 프리징을 원천 차단하기 위해 **GUI 프로세스를 별도의 서브스레드로 비동기 호출**하는 고도로 안정적인 구조를 채택했습니다.
  - 사용자가 폴더를 선택하면 대시보드 화면이 즉시 갱신되며 변경 사항이 `config.json` 및 백엔드 메모리에 **실시간 저장**됩니다.
* **인메모리 전역 갱신 및 디렉토리 자동 생성**: 
  - 경로를 지정하면 Flask 백엔드 메모리에 로드된 `backup` 모듈의 전역 변수들(`BASE_BACKUP_DIR`, `DB_DIR`, `MARKDOWN_DIR` 등)이 **실시간 재구성(Re-evaluation)**됩니다.
  - 동시에, 새로 지정한 디렉토리와 내부 필수 서브폴더(`db`, `enex`, `markdown`, `markdown/_resources`)들을 안전하게 자동 생성합니다.
  - 이후 진행되는 모든 백업 및 동기화 작업, 그리고 파일 시스템 쿼리들은 이 유동 폴더를 정확하게 상속받아 유기적으로 작동합니다.

### 2. UI 구조의 3단 카드 버튼 통합 단축 (Compact Card-Button Grid)
기존에 영역을 크게 차지했던 별도의 "백업 컨트롤 센터"와 "MD 브라우저 연동 센터" 카드 2개를 완벽하게 제거하고, 대시보드의 **3개 상태 진단 카드** 영역 하단에 관련된 액션 버튼들을 컴팩트하고 유기적으로 밀착 배치했습니다.

* **1단계 카드 (실행 라이브러리)**:
  - 의존성 진단 결과에 맞추어 즉각적인 후속 조치를 할 수 있도록 **`[🔑 로그인 인증 받기]`** 버튼을 통합 밀착시켰습니다.
* **2단계 카드 (에버노트 로그인)**:
  - 로그인 및 인증 정보를 바탕으로 실제 백업을 트리거할 수 있는 **`[🚀 원클릭 전체백업]`**, **`[🔄 증분 동기화]`**, **`[📁 ENEX 파일 추출]`**, **`[📝 마크다운 변환]`** 4개 버튼을 그리드로 압축 정렬했습니다.
* **3단계 카드 (백업 Notes)**:
  - 변환 및 수집된 마크다운 노트 현황을 토대로 백업 산출물에 바로 접근할 수 있도록 **`[📁 로컬 백업 폴더]`** 탐색기 열기 단추와 **`[💻 MD브라우저실행]`** 원클릭 연동 버튼을 나란히 하단에 배치했습니다.
* **MD 브라우저 서버 구동 감지 및 안내 모달 [NEW]**:
  - `[💻 MD브라우저실행]` 버튼 클릭 시, 5000번 포트 상태를 백엔드에서 실시간 스캔하여 `MDBrowser` Flask 서버의 생사 여부를 정밀 분석합니다.
  - 서버가 꺼져 있는 경우, 웹 페이지에서 즉각적으로 미려한 글래스모피즘 안내 팝업창(모달)을 실행하여 사용자에게 서버 구동의 필요성 및 **`C:\_My2026\_EVERBK\_MDBrower`** 폴더 내에서의 수동/자동 구동 스텝을 일목요연하게 시각적으로 안내합니다.
* **반응형 정렬 구조**: 카드가 가로로 좁아지더라도 글자가 카드 밖으로 넘치거나 깨지는 문제를 예방하기 위해 전용 크기 조정(Card-Specific Buttons Padding & Font Size) 스타일 규칙을 적용했습니다.
* **상단 빈 공간 여백 축소 (Ultra-Compact Header Layout) [NEW]**:
  - 화면 상단에서 영역을 크게 차지하던 컨테이너 상단 여백(`padding` 40px ➔ 15px), 헤더 하단 여백(`margin-bottom` 40px ➔ 16px), 그리고 저장소 경로 입력 패널(`.config-panel` 내 패딩 및 마진)의 간격을 촘촘하게 좁혀, 화면 진입 시 전체 요소가 한눈에 꽉 들어차도록 설계했습니다.

### 3. 실시간 터미널 뷰포트 스크롤 동기화
* 백업 작업 진행 중 콘솔 로그가 누적되어 터미널 영역 바깥으로 밀려날 때, 터미널 텍스트 스크롤은 물론 **브라우저 전체 페이지 뷰포트도 최하단으로 부드럽게 스크롤 동기화(`window.scrollTo({ behavior: 'smooth' })`)**되도록 처리하여, 진행 상태를 아무런 시각적 방해 없이 관측할 수 있습니다.

### 4. 경로 및 에버노트 노트북 파일명 안전 자동 교정 및 선제 경고 기능 [NEW]
* **로컬 폴더 경로명 자동 정제**: 사용자가 선택한 로컬 백업 폴더 경로명에 브라우저 오작동을 유발하는 작은따옴표(`'`) 또는 큰따옴표(`"`)가 포함된 경우, 저장 단계에서 자동으로 해당 부적합 문자를 제거해 정제한 후 즉시 경고 피드백 배너를 띄웁니다.
* **에버노트 노트북 이름 선제 경고 및 자동 교정 (`check_and_sanitize_notebooks`)**:
  - 동기화(`sync`), ENEX 파일 추출(`export`), 마크다운 변환(`convert`) 작업 시작 직전에 실시간 백업 파일 안전성 검증을 가동합니다.
  - SQLite 로컬 데이터베이스(`note.db`) 내 실제 노트북 명칭들과 생성된 ENEX 파일명들을 고속 전수 스캔합니다.
  - 작은따옴표(`'`), 큰따옴표(`"`) 또는 윈도우 생성 금지 문자(`\\/*?:"<>|`)가 포함된 노트북이 발견되면, 대시보드 실시간 터미널 화면에 즉각적으로 **경고 피드백을 노출**하고 브라우저/로컬 호환성이 확보된 안전한 디렉토리 이름으로 **자동 교정하여 백업 및 저장함**을 사용자에게 상세히 안내합니다.

## 🔬 API & 기능 단위 완벽 수동 검증 결과

실시간 REST API 상태 전이를 면밀하게 추적하는 화이트박스 검증 스크립트(`test_endpoints.py`)를 통해 다음과 같은 완벽한 검증 결과를 확인하였습니다.

```bash
[*] Testing /api/config GET...
[+] GET Response: {'base_backup_dir': 'C:/_My2026/_EVERBK'}

[*] Testing /api/config POST with new path...
[+] Directories verified/created at: C:\_My2026\_EVERBK_TEST
[+] POST Response: {'base_backup_dir': 'C:/_My2026/_EVERBK_TEST', 'message': '백업 폴더 경로가 변경 및 저장되었습니다.', 'success': True}

[*] Restoring original config...
[+] Directories verified/created at: C:\_My2026\_EVERBK
[+] Cleaned up test backup directory C:/_My2026/_EVERBK_TEST
[SUCCESS] All API tests passed perfectly!
```

* **GET `/api/config`**: 시스템 최초 시작 시 기본값 혹은 기설정된 `"C:/_My2026/_EVERBK"` 경로를 신속하고 정확하게 응답하는 상태를 확인했습니다.
* **POST `/api/config`**: 사용자가 경로를 `"C:/_My2026/_EVERBK_TEST"`로 임의 변경했을 때, 해당 경로에 맞추어 `config.json`이 변경되고, Flask 내부의 메모리 상태가 동적으로 동기화되며, 필요한 폴더 구조가 실시간으로 안전하게 자동 생성되는 복합 시나리오를 완벽하게 통과하였습니다.
* **원래대로의 복구 및 정리**: 검증 과정 중 생성된 임시 테스트 폴더들을 자동 정리하고 정상적으로 운영 상태로 회복함을 최종 확인하였습니다.
